    Reading the flow

    Each pill is a design token, and each line joins an alias to the token it references, ending at the values on the right.

    Moving around

    Move
    Drag, scroll, or the arrow keys
    Zoom
    Ctrl or Cmd and the wheel, or pinch with two fingers
    Steps
    + and -
    100%
    0, the page width
    Fit
    F, the whole flow on the screen

    Arrow keys pan, Shift and an arrow key pan further, plus and minus zoom, 0 resets to 100 percent, the page width, and F fits the flow to the screen.
